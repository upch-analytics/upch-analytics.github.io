# ФГИС УПЧ: единый вход

Сайт: https://upch-analytics.github.io/

Страница входа объединяет два рабочих места:

- **Представитель аппарата УПЧ**: панель аналитики обращений, https://upch-analytics.github.io/panel/ (репозиторий `upch-analytics/panel`).
- **Представитель ведомства**: ведомственная карта, https://upch-analytics.github.io/fgis-upch-map/ (репозиторий `upch-analytics/fgis-upch-map`, форк `daria71321-netizen/fgis-upch-map` с кнопкой «Выйти»; новые правки автора подтягиваются кнопкой «Sync fork» на GitHub).

Пользователь выбирает роль, вводит логин и пароль и попадает на свой сайт. Сайты остаются отдельными, страница входа только направляет. Оформление общее (Manrope и Unbounded, темная плашка, белая карточка), акцент меняется по роли: синий у панели УПЧ, красный у ведомственной карты.

Это демонстрационный вход для хакатона: подходят любые логин и пароль, данные никуда не отправляются и не сохраняются. Роль можно передать в адресе: `?role=upch` или `?role=gov`.

Весь сайт: один файл `index.html` без сборки. Публикация: GitHub Pages из ветки `main`. Адреса сайтов задаются в `TARGETS` внутри `index.html`.
